MULTIHOPPER · DEVELOPER REFERENCE

Give your agents
boundaries.

This local-only API creates jobs and exercises spending limits and recovery using synthetic assets. It is research software; do not use it with real funds.

Local demo: the NEAR mode runs on a disposable local node. Solana API and cross-chain settlement are not connected. Sessions and job state reset when the process stops.

Create a job

POST /api/jobs
Content-Type: application/json

{"jobId":"job1","budget":"100","limit":"25"}

Request an agent payment

POST /api/payments
Content-Type: application/json

{"jobId":"job1","invoiceId":"invoice1","amount":"20"}

Fail the job and recover eligible funds

POST /api/recover
Content-Type: application/json

{"jobId":"job1"}

Look up a Solana test transfer

GET /api/solana/transfers/{transferId}

Requires a verified wallet session and an operator-configured MultiHopper test API connection. The gateway only returns a minimal response for a test transfer owned by that wallet. This endpoint does not initiate a transfer or perform screening.

Wallet sessions

A compatible Solana wallet signs a one-time challenge through POST /api/auth/challenge and POST /api/auth/confirm. The server associates the resulting local session cookie with the wallet. Unauthenticated visitors share a demo identity; this is not production authentication.

Amounts are positive integer synthetic units. Requests and state belong to the current process. Read the existing MultiHopper Solana API documentation for that separate product.
